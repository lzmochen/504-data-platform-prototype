# V2.4 指标定义与规则配置（演示）

新增菜单：统计分析 → 指标统计、指标定义与规则配置。保留 V2.3 和原 monitor 目录不变。

## 已实现

- 指标新增、编辑、复制、搜索、状态筛选、保存草稿。
- 同源且同单位的分子/分母选择；统计范围、剔除状态、日/周/月及样例截止日。
- 分子分母分别汇总、逐设备比率等权平均；快照按设备去重取期内最新记录。
- 缺失或无效样本成对剔除/不出值；零分母不出值/按零计算。
- 目标、达标方向、展示预警值、小数位、百分点差/相对变化率、卡片绑定。
- 确定性样例试算及明细、无数据/全部缺失/零分母测试场景。
- 演示口径确认、模拟发布确认、发布版本、启停、实际修改前后记录。
- 同一浏览器、同一源下，中台与 monitor-v2 的三张卡片共享演示配置；草稿不会影响已发布版本。
- 保存持久化错误、多页版本冲突、重复编码/名称、看板槽位冲突校验。

## 明确边界

- 不是生产指标引擎，不调用任何采集、设备、生产、工艺或报警接口。
- 原定义仅用作待客户确认的表单初值。目标 95% 延用旧原型展示，并非建议的生产目标；其他目标和预警默认为空。
- 样例设备编号 DEMO-001 等，样例截止日固定 2026-09-28，与生产无关。已有看板三张原始样例在未发布规则时保留静态值并标注“规则待发布”；不会伪称规则已经生效。
- 日界线北京时间 00:00；周从周一开始，月从 1 日开始。按日汇总的固定样例不模拟任意班次、跨日时段拆分或真实采集刷新。对比为上一等长周期，不冒充同比。
- 草稿“演示口径确认”不是客户正式确认，也不是实际审批。卡片阈值只决定展示颜色，不下发设备控制或生成生产告警。
- 仅新增指标模块使用 localStorage 的 `504-kpi-demo-v1` 保存；不上传、不跨设备同步。其他旧模块仍保持原来内存演示行为。浏览器无保存权限时明确提示失败，不伪称成功。
- 公开 GitHub Pages，没有真实登录鉴权。勿录入真实生产数据、密钥或敏感资料。
- 当前模块不提供删除或重置入口，以免误清除评审中的配置。停用保留发布版本和记录。
