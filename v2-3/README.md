# V2.3 确定性逻辑修订版

基于 V2.2（2026-09-23）及《504数据平台原型业务评审报告20260924》，按用户确认范围局部修订。V2.2 和监盘原型保持原样。

## 已修订

| 评审编号 | 范围 | 本版处理 |
| --- | --- | --- |
| 02 | 用户授权 | 回显选中账号的当前数据范围；保存后更新列表，取消不变更。不定义角色与个人授权的优先级。 |
| 03 | 操作日志 | 历史日志显示该行对象；缺失的历史快照显示空态。会话内设备、测点、用户、规则、基础资料、报警确认等操作记录实际前后差异。 |
| 18、19 | 字典、基础资料 | 补全已有列表字段；区分业务字典与设备基础资料，记录具有稳定标识。新增、编辑、删除对应正确记录；重复标识校验；已知被引用标识不直接删除或更名。 |
| 20 | 规则录入 | 编辑回显原条件，保留单条件规则；测点切换联动单位并清空旧阈值。数值输入必填；非数值测点不使用数值表单。未修改原有阈值和等级口径。 |
| 05 | 层级数量 | 根节点改为 14,438，与原有三个产线分项之和及台账示例口径一致，不新增统计定义。 |
| 06 | 导入确认 | 提供跳过/更新两种明确策略，统一新增、更新、跳过、失败、总量。保留为预置样例流程，结果明确为模拟、未写入台账。 |
| 15、24 | 告警消息 | 按事件号直达详情；阅读仅改变消息已读状态；确认报警为独立操作并产生日志；未读角标同步。 |
| 08、09 | 趋势、时间 | 报警与设备详情不再套用无关曲线；缺少关联历史样本时显示空态，规则试算不再伪造命中结果。实时查询不使用“刚刚”冒充采集时间；侧栏标明演示模式。 |

## 明确保留待业务确认

- 报警等级排序、阈值边界、历史规则版本与样例冲突。
- 报警派发、处置、恢复、关闭、升级、抑制及责任岗位。
- 规则审批、生效、版本、回退、范围及权限继承。
- 型号是否唯一决定制造商/类型，主数据停用后的历史兼容及迁移。
- 组织树与生产层级的映射、状态来源、统计分母和采集超时。
- 消息生成、收件人、发送渠道、去重和重试。
- 查询多测点选取及跨单位坐标轴；阀位数据类型与物理量样例需核对点表。

本次不调整数据标签、数据服务、数据质量、数据安全四个模块，不恢复已删除的菜单，不扩展实际业务审批流程。

## 演示边界

- 全部操作只改变当前浏览器页面内存；刷新恢复初始样例。
- 无生产系统连接。历史样例、汇总指标不作为生产判断依据。
- 页面内“用户授权”只是交互演示，并非网站登录、访问控制或真正的权限隔离。
- 此版本沿用公开 GitHub Pages；访问密码未配置。
